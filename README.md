# IIDXChordSearch

IIDXChordSearch is a static web tool for searching beatmania IIDX SP charts by chord pattern, level, BPM, difficulty, artist, and Notes Radar attributes. Results are ranked by chord pattern count and link directly to the corresponding Textage chart pages.

This project is designed mainly for beginner and intermediate IIDX players who want to find songs for practicing specific hand patterns. It is especially useful for practicing 3/4 split and 2/5 split playstyles.

*If you are not familiar with 3/4 split or 2/5 split playstyles, we recommend checking [iidx.org](https://iidx.org).*

## Features

- Search SP charts by scratch/key chord pattern.
- Switch between 1P and 2P pattern layouts.
- Filter by level range, BPM range, difficulty, artist, and dominant Notes Radar attribute.
- Show Notes Radar summaries for `NOTES`, `PEAK`, `SCRATCH`, `SOF-LAN`, `CHARGE`, and `CHORD`.
- Sort results by pattern count.

## Data Sources

- Chord counts are parsed from [Textage](https://textage.cc/score/index.html), a beatmania IIDX chart database.
- Notes Radar values are based on data from [@NotesRadarBot](https://x.com/NotesRadarBot).
- SP playstyle terminology references [iidx.org](https://iidx.org/compendium/sp_playstyle).
